## Purpose

The VEES Architecture Constitution defines the mandatory architectural principles governing the entire platform.

Every source file, bounded context, aggregate, service, event, repository, and integration must comply with this Constitution.

If an implementation conflicts with this Constitution, the Constitution prevails.

---

## Scope

This Constitution applies to:

- All Bounded Contexts
- Shared Kernel
- Application Layer
- Infrastructure Layer
- API Layer
- Database Layer
- Future Services
- Tests
- Documentation

---

## Authority

This Constitution has higher authority than:

- ADRs
- Coding Standards
- Design Documents

ADRs explain decisions.

The Constitution defines immutable architectural rules.
