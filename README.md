# Vees Core

Vees Core is the domain and application kernel used by the Vees platform.

## Features

- Domain-Driven Design (DDD)
- Clean Architecture
- CQRS
- Transactional Command Bus
- Domain Events
- Shared Kernel
- Laravel Integration Layer

## Requirements

- PHP 8.3+
- Laravel 12

## Installation

```bash
composer require vees/vees-core
```
